## 🛡️ نظرة عامة على المشروع (Project Overview)
**MR.SALL** هي منصة تعليمية إلكترونية متكاملة ومصممة بأحدث معايير الويب لتقديم محتوى تعليمي متخصص في مجالات الأمن السيبراني (Cybersecurity)، الاختراق الأخلاقي (Ethical Hacking)، وحماية البيانات.

الموقع مبني بالكامل باستخدام:
- **HTML5** دلالي ومعياري بالكامل.
- **CSS3** متقدم بتأثيرات السايبر الحديثة (Cyberpunk / Modern Defense HUD) وألوان النيون الخضراء (`#00ff9d`) والزرقاء الكهربائية (`#00d2ff`).
- **Vanilla JavaScript** خالص وخفيف دون أي مكتبات أو أطر عمل خارجية (No React, Vue, Angular, or Bootstrap).

## 🚀 توافق النشر الفوري على نتليفاي (Netlify Deployment)
المشروع جاهز 100% للرفع المباشر على منصة **Netlify**:
1. ملف `index.html` موجود في المجلد الرئيسي للجذر (Root).
2. جميع الروابط ومسارات الصور والملفات هي مسارات نسبية (`relative paths`).
3. لا يتطلب أي خادم خلفي (Zero Backend / Serverless).
4. لا يتطلب أي مفاتيح API مدفوعة.
5. يتضمن ملفات وسائط مصغرة محلية مجهزة في مجلد `assets/`.

### خطوات الرفع على Netlify:
1. افتح حسابك على [Netlify](https://www.netlify.com/).
2. انتقل إلى تبويب **Sites** ثم اسحب مجلد المشروع بالكامل وأفلته في منطقة **Drag and drop your site output folder here**.
3. سيعمل الموقع فورياً ويكون متاحاً برابط مباشر وسريع.

يتضمن المشروع صفحة مقدمة سينمائية مستقلة `intro.html` بدقة **1080p Full HD (1920x1080)** وبسرعة **60 إطار بالثانية (60 FPS)**:

- **المشهد 2 (Hacker Atmosphere):** بيئة اختراق سيبرانية مستقبلية بأرضية ثلاثية الأبعاد (Perspective Grid)، تدفق سريع لحزم البيانات، أوامر طرفية متحركة، وأشعة مسح رقمية.
- **المشهد 3 (3D Logo Reveal):** انبثاق الشعار الرسمي لـ **MR.SALL** بتدوير ثلاثي الأبعاد ولمعان معدني واقعي مع هالة نيون مضيئة، موجات صدمة متتالية، وشرارات كهربائية تحيط بالدرع.
- **المشهد 4 (Brand Reveal):** ظهور اسم المنصة والشعار الدقيق بتأثير Glitch وتقسيم لوني لوني (RGB Splitting):
  ```text
  MR.SALL
  CYBERSECURITY ACADEMY
  "LEARN. PROTECT. INNOVATE."
  ```
- **المشهد 5 (Final Transition):** انفجار طاقة ضوئية خضراء وانتشار لآلاف الجزيئات الرقمية ثم انتقال سلس إلى الصفحة الرئيسية للموقع.
- **تصدير فوري بنقرة واحدة كفيديو MP4:** زر `Export MP4 (1080p)` لتسجيل وتحميل الفيديو بدقة 1080p مباشرة مع المؤثرات الصوتية المركبة صوتياً (Web Audio API).
- **إمكانية رفع أي شعار مخصص:** زر ومنطقة إفلات (Drag & Drop) تتيح رفع أي صورة شعار بصيغة PNG أو SVG وتوليد الانعكاس المعدني ثلاثي الأبعاد عليه فورياً!
